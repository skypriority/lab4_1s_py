# Факториал: рекурсия vs цикл 

Бенчмарк, сравнивающий производительность **рекурсивной** и **итеративной**
реализаций функции вычисления факториала на Python.

![График результатов](factorial_benchmark.png)

## Описание

Скрипт замеряет время работы двух функций с помощью модуля `timeit`
и строит график зависимости времени выполнения от входного числа `n`
средствами `matplotlib`.

Реализованы две функции:

| Функция | Подход | Время | Память (стек) |
|---|---|---|---|
| `fact_recursive(n)` | рекурсия | O(n) | O(n) |
| `fact_iterative(n)` | цикл `for` | O(n) | O(1) |

##  Методика измерений

Применяется методика **«чистого бенчмарка»** одного вызова:

1. **Один фиксированный набор данных** для обеих функций:
   `ns = [10, 50, 100, 200, 300, 400, 500, 700, 900]`
2. **Многократные прогоны** — `timeit.repeat` выполняет
   `REPEAT = 5` прогонов по `NUMBER = 1000` вызовов каждый
   (итого 5000 вызовов на каждую пару *(функция, n)*).
3. Берётся **минимум** из прогонов — самый «чистый» результат,
   наименее искажённый фоновой активностью ОС.
4. Результат нормируется на число вызовов → время **одного вызова** в мкс.

##  Запуск

```bash
# Клонировать репозиторий
git clone https://github.com/<ваш-логин>/factorial-benchmark.git
cd factorial-benchmark

# Установить зависимости
pip install -r requirements.txt

# Запустить бенчмарк
python factorial_benchmark.py
```

После запуска:
- в консоль выводится таблица результатов;
- график сохраняется в файл `factorial_benchmark.png`
  (удобно для Replit и других сред без GUI).

##  Пример вывода

```
    n |  рекурсия, мкс |  цикл, мкс | во сколько раз
-------------------------------------------------------
   10 |           0.85 |       0.42 |          2.02x
   50 |           4.10 |       1.95 |          2.10x
  100 |           8.55 |       4.20 |          2.04x
  200 |          17.90 |       9.10 |          1.97x
  500 |          55.20 |      31.40 |          1.76x
  900 |         160.34 |      95.12 |          1.69x
```

##  Выводы

- Обе функции имеют линейную сложность **O(n)** — обе линии на графике
  растут примерно линейно (небольшая нелинейность на больших `n`
  вызвана ростом стоимости умножения длинных чисел).
- **Итеративная версия стабильно быстрее в ~1.5–3 раза**: рекурсия несёт
  накладные расходы на каждый вызов функции (создание кадра стека,
  передача аргументов, возврат значения).
- Рекурсия дополнительно ограничена глубиной стека — в скрипте лимит
  поднят до 10000 через `sys.setrecursionlimit(10000)`, иначе
  `fact_recursive(900)` завершился бы с `RecursionError`.

**Итог:** для вычисления факториала итеративный подход эффективнее
и по времени, и по памяти.

##  Требования

- Python 3.8+
- matplotlib

##  Ограничения

- Функции не валидируют вход (отрицательные/нецелые `n` не обрабатываются) —
  осознанное упрощение для бенчмарка.
- Абсолютные значения времени зависят от машины и версии интерпретатора;
  воспроизводимы только относительные соотношения.
